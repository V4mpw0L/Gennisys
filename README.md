## 🧭 About Syscorv

**Syscorv** (*System + Corvo / Raven*) is an independent technology corporation and software engineering laboratory founded by **Tiago Cardoso (v4mpw0l)**. 

Inspired by the acute perception, strategic autonomy, and high intellect of the raven, Syscorv rejects the brittle fragilities of modern cloud lock-in and surveillance-driven platforms. We design, register, and deploy proprietary software solutions engineered to endure.

### 🏛️ Core Engineering Directives

1. **Local-First Resilience**: Software that stores state client-side (IndexedDB / CacheStorage) and functions with 100% operational capability regardless of internet connectivity.
2. **Zero-Knowledge Privacy**: Privacy safeguarded by mathematical architecture. Zero trackers, zero invasive telemetry, zero third-party brokers.
3. **Computational Efficiency**: Handcrafted in modern Vanilla JS, Web APIs, and GPU-accelerated CSS pipelines ensuring instant boots and sustained 60 FPS responsiveness.
4. **Enduring Digital Craftsmanship**: High-contrast obsidian & cyber-blue aesthetics, meticulous typography, and robust software foundations.
